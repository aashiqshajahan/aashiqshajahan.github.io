## There is more here than meets the eye.

MuziriSpace is not introducing itself with a long explanation. It is opening a door with a question.

**What happens when a new possibility begins to take shape?**

This single-page experience is the first signal: a cinematic, interactive *coming soon* page designed to spark curiosity, invite exploration, and leave visitors wanting to know what comes next.

## Built to be lightweight

The experience is intentionally self-contained in `index.html`.

- **No framework or build step:** no React, npm install, bundler, or compilation required.
- **No backend dependency:** the interactions run in the visitor's browser.
- **Responsive layout:** adapts to desktop, tablet, and mobile screens.
- **Motion-aware:** respects the device's reduced-motion preference.
- **Accessible interaction basics:** semantic sections, keyboard-visible focus, labelled interactive nodes, and status announcements.
- **Performance-conscious animation:** decorative particles are lightweight and capped, especially on smaller screens.

The visual experience uses CSS effects and a small Canvas animation rather than loading a collection of large assets.

## Run it locally

1. Clone or download this repository.
2. Open `index.html` directly in a browser.
3. Explore the clue cards, constellation game, and final message.

No build command is needed.

## Publish with GitHub Pages

This repository is configured as a GitHub Pages site.

1. Open the repository on GitHub.
2. Edit or replace `index.html` in the publishing branch.
3. Commit the changes.
4. Wait for the GitHub Pages deployment to complete.
5. Visit [muzirispace.me](https://muzirispace.me) and check both desktop and mobile layouts.

If the custom domain or HTTPS is not working, review **Settings → Pages** and the domain's DNS configuration. Avoid changing working DNS records just to update the page content.

## Before the big reveal

This page is the beginning of the story, not the complete investor presentation.

As the venture becomes ready to announce, the next version can introduce:
- The real problem being solved and the people it serves.
- The product or service and its differentiating value.

Those details should be added when they are confirmed. Until then, the mystery is deliberate.

## A small note on the current interactions

The constellation clues and “last hint” are client-side interactions. They do not collect personal information, send emails, or store visitor signups. The page currently has no analytics or database integration.

If a real waitlist is added later, connect it to a trusted form or backend and explain clearly what information is collected and why.
